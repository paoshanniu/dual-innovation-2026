## 数据与口径

- 数据源：通达信本地日线（A2，已更新至 2026-11-25 收盘）、腾讯 qt.gtimg.cn / web.ifzq.gtimg.cn（A3）。11-25 当日东方财富 push2 行情接口返回空值，本轮快照未采用 A4。
- 统计口径：收盘价、不复权；100 日滚动＝全部重叠窗口；年化斜率＝对数价格对交易日回归斜率 ×250；峰值对齐＝各自高点后第 N 个交易日；波动率＝前 20 日日收益标准差；情景算术＝峰值 ×(1-累计跌幅)，仅作坐标换算。
